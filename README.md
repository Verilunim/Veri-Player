# 🎵 Veri Player

**Эстетичный музыкальный плеер для Windows** с поддержкой AI-генерации треков, анимированными фонами и облачными интеграциями.

## ✨ Возможности

### 🎨 Визуальная эстетика
- **Анимированные фоны**: Снег, дождь, листья, сакура, звёзды, пузыри, светлячки, угли
- **Кастомные фоны**: Загрузка изображений (min 1920×1080) и MP4-видео (до 5 сек)
- **RGB-тематизация**: Выбор цвета темы через палитру
- **Плавные переходы**: Crossfade между треками, анимированные переходы между вкладками
- **Fullscreen обложек**: Полноэкранный просмотр с плавным показом/скрытием

### 🎵 Работа с музыкой
- **Импорт**: Файлы MP3, FLAC, WAV, M4A, OGG, WMA
- **Метаданные**: Редактирование title, artist, album, genre, year
- **Обложки**: Загрузка/обрезка квадратных обложек
- **Фоновые клипы**: MP4-видео до 5 секунд для каждого трека
- **Плейлисты**: Создание, редактирование, экспорт
- **Избранное** и **история прослушиваний**
- **Для вас**: библиотека сама поднимает наверх треки, исполнителей и жанры, которые вы слушаете чаще
- **Статистика**: сколько всего минут музыки прослушано (копится между входами), любимый исполнитель и жанр в профиле

### 🤖 AI-генерация
- **Suno AI интеграция**: Создание треков по текстовому описанию
- **Параметры**: Стиль, текст песни, странность, вовлечение в стиль
- **История генераций**: Сохранение всех созданных треков
- **Прямое добавление в библиотеку**

### 🔗 Облачные интеграции
- **SoundCloud**: вход в аккаунт, ваши треки, лайки и плейлисты — играют прямо в Veri Player
- **YouTube Music**: вход через Google, понравившиеся и плейлисты — треки открываются в YouTube Music (звук отдельно от их плеера правила YouTube не разрешают)
- **Spotify**: Подключение аккаунта, импорт плейлистов, синхронизация
- **Yandex Music**: Импорт библиотеки (в разработке)

Для SoundCloud и YouTube Music нужны ключи своего приложения (Client ID и Client Secret) — пошаговая инструкция на странице сервиса в программе. Ключи и токены хранятся зашифрованными (DPAPI).

### 📤 Шеринг
- **QR-коды**: Генерация QR для мгновенной передачи
- **Ссылки**: Передача метаданных или полного файла (до 16 MB)
- **Схема URI**: `veriplayer://track/...`

### ⭐ Подписка Pro+
- **Что входит**: редактирование песен (названия, обложки, клипы), оформление (RGB-цвета, эффекты фона, свой фон) и создание музыки с AI
- **Без Pro+** эти функции видны с замком 🔒, а по клику открывается окно Pro+; оформление — стандартное
- **Активация**: кнопка **Pro+** в шапке → **Ввести ключ активации** → вставить ключ
- **Ключи** подписаны цифровой подписью (ECDSA P-256) и привязаны к нику: подделать ключ или включить Pro+ правкой файлов нельзя
- **Срок**: 7/30/90/180 дней, год, до выбранной даты или бессрочно; перевод часов назад не продлевает подписку
- **Золотой ➕ у ника** у подписчиков и приветствие один раз после активации
- Владелец и со-владелец получают Pro+ автоматически

### 👥 Система аккаунтов
- **Локальные профили**: Ник, пароль, аватар, био
- **Роли**: Owner, Co-owner, User
- **Панель администратора**: Мониторинг пользователей, выдача ключей Pro+ (Owner/Co-owner)
- **Встроенная команда**: владелец Verilunim и со-владелец Jomapel есть в каждой установке; в программе хранится только хэш их паролей, пароли задаются командой `VeriKeygen staff`
- **Защита паролей**: PBKDF2-SHA256 (600 000 итераций), минимум 8 символов для владельца и со-владельца, блокировка входа после 5 неверных попыток
- **Шифрование**: `users.json` зашифрован ключом учётной записи Windows (DPAPI)

### 🎮 Управление
- **Горячие клавиши**: Space (play/pause), Left/Right (prev/next), Ctrl+M (mute)
- **Системный трей**: Показ прогресса трека в tooltip
- **Drag & Drop**: Перетаскивание файлов/папок для импорта
- **Контекстные меню**: Полный набор действий для каждого трека

### 🛠️ Диагностика
CLI-команды для тестирования работают **только в Debug-сборке** (в релизном exe отключены):
- `--demo` — фиктивная библиотека
- `--login nick:pass` — автовход
- `--play <index>` — запуск трека
- `--modal <name>` — открыть панель
- `--audit <path>` — проверка UI-геометрии
- `--sharetest` — тест шеринга

## 🚀 Использование

### Первый запуск
1. Зарегистрируйтесь: **Регистрация** → ник и пароль (владелец и со-владелец входят в свои встроенные аккаунты)
2. Добавьте музыку: **кнопка "+"** → Файлы/Папки
3. С Pro+ настройте оформление: **эффекты фона**, **RGB-палитра** и **свой фон** — кнопки в шапке

### Активация Pro+
1. Сообщите владельцу свой ник — ключ выпускается под конкретный аккаунт
2. **Pro+** в шапке → **Ввести ключ активации**
3. Вставьте ключ (`VPRO-…`) → **Активировать**
4. При следующем запуске вас встретит приветствие подписчика, а у ника появится золотой ➕

### Выпуск ключей Pro+ (только владелец и со-владелец)
1. Один раз создайте пару ключей подписи: `dotnet run --project tools/VeriKeygen -- init`
   - Закрытый ключ сохраняется в `%USERPROFILE%\.veriplayer\license-private.pem` — **сделайте резервную копию и никому не передавайте**
   - Открытый ключ впишите в `LicenseService.PublicKey` и пересоберите программу
2. В программе: **Админ-панель** → пользователь → **Ключ Pro+** (или **Pro+** → **Выпустить ключи Pro+**)
3. Введите **API-ключ выпуска** (`XXXXXXXXXXXXXXXXXXXX-XXXXXXXXXXXXXXXXXXXX`) → **Разблокировать**
   - Закрытый ключ подписи встроен в программу только зашифрованным (AES-256-GCM, ключ из API-ключа через PBKDF2) — без API-ключа выпустить Pro+ нельзя
   - Сам API-ключ в коде не хранится; после 5 неверных попыток ввод блокируется на 2 минуты
4. Выберите срок → **Создать ключ** → скопируйте и отправьте пользователю
5. Там же: **Определить срок ключа** (для кого, до какого числа, настоящий ли) и журнал выданных ключей
6. Без программы — из консоли: `dotnet run --project tools/VeriKeygen -- issue <ник> --days 30` (или `--until 2026-12-31`, `--lifetime`)

### AI-генерация (Pro+)
1. Получите API ключ на [sunoapi.com](https://sunoapi.com) (от $5)
2. Боковое меню → **Создать песню**
3. Вставьте ключ, опишите стиль и текст
4. Дождитесь генерации (~1 минута) → **Добавить в библиотеку**

### Шеринг треков
1. **ПКМ по треку** → **Поделиться треком**
2. Выберите режим: **Метаданные** (QR + короткая ссылка) или **С файлом** (длинная ссылка)
3. **Копировать ссылку** или **Сохранить QR**
4. Получатель: **Вкладка "Добавить по ссылке"** → вставить → **Добавить**

## 🔧 Архитектура

### Сервисы
- **AudioService**: NAudio, crossfade, repeat/shuffle, позиция
- **LibraryService**: Импорт, CRUD треков, query
- **AuthService**: Локальные аккаунты, PBKDF2-хэши, блокировка входа, первый запуск
- **LicenseService**: Pro+ — проверка подписи ключей, выпуск и проверка срока (для команды)
- **ShareService**: Сборка/парсинг ссылок, base64url, QR
- **QrEncoder**: Чистый C# QR-генератор (EC level M, версии 1-40)
- **SpotifyService**: OAuth PKCE, импорт плейлистов
- **MusicGenService**: Suno API, генерация, история
- **TrayService**: NotifyIcon, tooltip с прогрессом
- **BackgroundService**: Управление фонами, клипами
- **Storage**: %AppData%\VeriPlayer (JSON, атомарная запись; аккаунты под DPAPI)

### UI
- **WPF + XAML**: Custom theme, glass panels
- **ParticleField**: Canvas-based анимации (8 эффектов)
- **MainWindow**: Shell (sidebar + content) + Auth overlay
- **PlayerView**: Треки, транспорт, seek bar
- **Панели**: Track edit, effects, settings, Spotify, generate music, share, add by link

## 🎨 Дизайн

- **Палитра**: Stepped tonal ladder (5-7 уровней, #05070C → #1E2636)
- **Акценты**: Luminous accent (#38BDF8 и т.д.) + muted supporting tint
- **Типографика**: Fluid scale (clamp()), custom properties
- **Layout**: CSS Grid-first (для section rhythm), flex внутри компонентов
- **Компоненты**: Tokenized (spacing, radius, shadow через var())
- **Геометрия**: Fully rounded (999px pills, 50% circles)
