# Генерация музыки через Suno AI (версия 1.1.0.0+)

## Что это?
Veri Player теперь умеет **создавать песни** с помощью искусственного интеллекта Suno.  
Вы пишете промпт (стиль/настроение), текст песни (или выбираете инструментальную) — и получаете **2 варианта трека** за 1–2 минуты.

---

## Как настроить?

### 1. Получите API ключ

Официального публичного API у Suno нет, но есть неофициальные провайдеры:

#### Вариант A: **sunoapi.com** (рекомендуемый)
1. Зарегистрируйтесь на https://www.sunoapi.com/
2. Пополните баланс (от $5, ~$0.08 за 2 трека)
3. Скопируйте API ключ из личного кабинета

#### Вариант B: **Собственный сервер** (продвинутый)
Если вы программист, можете развернуть свой прокси-сервер:
- https://github.com/gcui-art/suno-api (Node.js)
- Нужна подписка Suno Pro ($10/мес) и cookies из браузера

---

### 2. Вставьте ключ в Veri Player

1. Откройте **Настройки** → **Сервисы**
2. Найдите поле **Suno API Key**
3. Вставьте ваш ключ и нажмите **Сохранить**

Или вручную в файл `%AppData%\VeriPlayer\settings.json`:
```json
{
  "SunoApiKey": "ваш-ключ-здесь"
}
```

---

## Как использовать?

### В приложении:
1. Перейдите на вкладку **"Создать песню"** (иконка волшебной палочки)
2. Заполните форму:
   - **Промпт стиля** — описание жанра/настроения (на английском или русском)  
     *Пример: "energetic pop with 80s synth and female vocals"*
   - **Текст песни** — если хотите песню со словами  
     *Или поставьте галочку "Инструментальная песня"*
   - **Странность** (0-100) — насколько эксперементальным будет звучание
   - **Вовлечение в стиль** (0-100) — насколько строго AI следует промпту
   - **Убрать элементы** — что **не** должно быть в песне  
     *Пример: "no guitar, no drums, no vocals"*

3. Нажмите **"Создать 2 варианта"**
4. Подождите 1–2 минуты (статус обновляется автоматически)
5. Прослушайте результаты и добавьте понравившиеся в библиотеку

## Ограничения

- **Макс. длина промпта:** 200 символов
- **Макс. длина текста:** 3000 символов (или галочка "Инструментальная")
- **Генерация:** ~60–120 секунд за 2 трека
- **Качество:** зависит от подписки Suno (Pro = лучше)
- **Формат:** MP3, ~30 секунд (стандарт Suno v3)

## Стоимость

- **sunoapi.com:** ~$0.08 за генерацию (2 трека)
- **Suno Pro подписка:** $10/месяц (500 кредитов) через официальный сайт

## Проблемы?

### "Не удалось создать песню: Ошибка API"
- Проверьте, что API ключ вставлен правильно
- Убедитесь, что на балансе sunoapi.com есть средства
- Попробуйте сократить промпт/текст

### "Генерация застряла на 'queued'"
- Подождите до 3 минут (очередь на сервере Suno)
- Проверьте статус вручную на sunoapi.com dashboard

### Песня создалась, но не скачалась
- Проверьте интернет-соединение
- В истории генераций есть кнопка "Скачать снова"

---

## История генераций

Все созданные треки сохраняются в:
- **UI:** вкладка "Создать песню" → раздел "История"
- **Файл:** `%AppData%\VeriPlayer\generated.json`
- **MP3:** `%AppData%\VeriPlayer\generated\<id>.mp3`
