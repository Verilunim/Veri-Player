## Veri Player 1.2.0.0

Большое обновление: подписка **Pro+**, новая защита аккаунтов и десяток исправлений.

### ⭐ Pro+
- **Что входит:** редактирование песен (названия, обложки, клипы на фон), оформление (RGB-цвета, эффекты фона, свой фон) и создание музыки с AI.
- **Активация по ключу:** кнопка **Pro+** в шапке → **Ввести ключ активации**. Ключ выпускается под ваш ник — сообщите его владельцу.
- **Ключи с цифровой подписью:** подделать ключ или включить Pro+ правкой файлов нельзя; перевод часов назад не продлевает подписку.
- **Золотой ➕ у ника** у подписчиков и приветствие при первом запуске после активации.
- Без Pro+ платные функции видны с замком 🔒, оформление — стандартное. Ваши прежние настройки сохраняются и вернутся с подпиской.
- **Для владельца и со-владельца:** окно «Ключи Pro+» в админ-панели — выпуск ключей на 7/30/90/180 дней, год, до даты или бессрочно, проверка срока любого ключа и журнал выданных.

### 🔐 Безопасность
- **Нет зашитых аккаунтов.** При первом запуске владелец сам задаёт ник и пароль. Если у владельца остался старый стандартный пароль, программа попросит задать новый; со-владельцу пароль задаёт владелец в админ-панели.
- **Пароли:** PBKDF2-SHA256 на 600 000 итераций (старые хэши обновятся при входе), минимум 8 символов для владельца и со-владельца, блокировка входа после 5 неверных попыток (от 30 секунд до 15 минут).
- **Аккаунты зашифрованы** ключом вашей учётной записи Windows (DPAPI).
- Ссылка «Поделиться» больше не может записать файл за пределы папки программы.
- Ключ Suno API отправляется только на сервер Suno.
- Проверка `state` при подключении Spotify.
- Отладочные ключи командной строки отключены в релизной сборке.

### 🐞 Исправления
- Данные сохраняются атомарно — сбой при записи больше не обнуляет библиотеку или аккаунты.
- Визуализатор показывает верный спектр для стерео-треков.
- «Удалить файл с диска» теперь удаляет и трек, который сейчас играет.
- Повторный импорт той же папки при включённом копировании не создаёт дубли.
- AI-генерация, начатая перед закрытием программы, продолжается после перезапуска.

### ⚠️ Важно
- Exe не подписан цифровой подписью: при первом запуске Windows SmartScreen может показать «Неизвестный издатель» → **Подробнее** → **Выполнить в любом случае**.
- Файл аккаунтов зашифрован под вашу учётную запись Windows: перенести `users.json` на другой компьютер нельзя — там аккаунт нужно создать заново.
