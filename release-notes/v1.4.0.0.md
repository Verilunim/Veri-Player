## Veri Player 1.4.0.0 — SoundCloud и YouTube Music

Ваша музыка из SoundCloud и YouTube Music — теперь в Veri Player. В боковом меню появились два новых раздела.

### ☁️ SoundCloud
- Вход в ваш аккаунт через браузер.
- **Мои треки**, **Лайки** и **Плейлисты** — с обложками.
- Треки **играют прямо в Veri Player**: нажмите на трек — весь список станет очередью. В главном блоке видно «Сейчас играет · SoundCloud».
- Правой кнопкой мыши → «Открыть на SoundCloud» — страница трека на сайте.
- Некоторые треки SoundCloud отдаёт только в формате, который плеер пока не поддерживает, — их можно открыть на сайте.

### ▶️ YouTube Music
- Вход через Google (доступ только для чтения).
- **Понравившиеся** и **Плейлисты**.
- Треки открываются в YouTube Music: правила YouTube не разрешают проигрывать звук отдельно от их плеера.

### 🔧 Как подключить
Для каждого сервиса нужно один раз создать своё приложение и вставить его ключи (Client ID и Client Secret) на странице сервиса — там же пошаговая инструкция и кнопка, открывающая нужный сайт.
- **SoundCloud:** портал разработчиков SoundCloud → зарегистрировать приложение → Redirect URI `http://127.0.0.1:8897/callback`.
- **YouTube Music:** Google Cloud Console → включить YouTube Data API v3 → OAuth-клиент типа «Desktop app» → добавить свой аккаунт в Test users.

Ключи и токены хранятся на вашем компьютере в зашифрованном виде.
